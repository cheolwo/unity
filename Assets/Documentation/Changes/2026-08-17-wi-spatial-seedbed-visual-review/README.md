# E4 WI 공간 모판 시각 검토 기록

이 폴더는 위치 독립적인 E4 WI 공간 모판을 Unity Play Mode에서 검토한 화면 증거다.
`WI공간모판검토실`은 서버 상태나 E5 배치를 결정하지 않는 읽기 전용 표현 Scene이다.

## 화면 묶음

- `01-e4-seedbeds-overview-game-view.png`: 5개 모판과 9개 내부 공간의 전체 흐름
- `02`, `04`, `06`, `08`, `10`: 각 모판의 첫 공간·첫 경관 후보 대표 화면
- `03`, `05`, `07`, `09`, `11`: 각 모판이 허용하는 고유 경관 후보 비교 화면

검토 대상은 농장 생산, 농장 작업마당, 농장 상차·Gate, Farm–Hub 화물회랑,
Hub 입고·보관의 다섯 모판이다. 전체로는 13개 E3 WI, 9개 내부 공간,
27개 고유 경관 후보가 연결된다.

## 증거 수준과 경계

- Unity 6000.5.6f1 실제 Play Mode의 Game View를 1600×900으로 캡처했다.
- 원본 E4 JSON과 Unity 경관 구성 대장·Synty Binding의 SHA-256 계보를 Visual Catalog에 보존했다.
- 후보 Prefab은 원형 크기로 표시하며 자동 축척하지 않는다.
- 연결선은 E4 연결구의 흐름을 이해하기 위한 미리보기다.
- 이 화면은 실제 도로, 교차로, Block, 좌표, E5 배치 승인 또는 운영 상태를 뜻하지 않는다.
