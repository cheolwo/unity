# ARC-F3 일반 타로 턴 화면

`SimulationWorldShell`의 턴 마감 패널을 서버가 결정한 일반 타로 3장 제안과 O6 배치 객체 반응 미리보기에 연결했다.

## 화면 흐름

1. 서버의 현재 턴 마감 맥락에서 타로 제안 3장과 정·역방향을 읽는다.
2. 사용자가 한 장을 선택하면 별도 객체 반응 미리보기를 조회한다.
3. 현재 Simulation 상태가 있는 O6 배치 객체만 황금색 원으로 강조한다.
4. 턴 마감 Preview는 기준 상태를 변경하지 않는다.
5. Confirm 뒤 서버 기준 세션을 다시 조회해 다음 날을 표시하고 임시 강조를 제거한다.

기존 `턴카드모판`의 학당·문화 카드는 연구·검증 화면으로 보존했다. 실제 경영 화면의 일반 타로와 고유 식별자·효과 권위를 섞지 않는다.

## Game View

- [서버 타로 3장 제안](tarot-three-offers.png): 서버가 결정한 제안 3칸, 정·역방향, 기회와 부담을 표시한다.
- [현재 영향 객체 강조](tarot-object-highlight.png): 정착지 내부에서 현재 관련 상태가 있는 도심마트 객체만 강조한 결과다.
- [다음 날 기준 상태 재조회](tarot-next-day.png): 턴 확정 뒤 상태 버전이 0에서 1로 바뀌고 임시 강조가 제거된 결과다.

## 검증과 경계

- 새 Unity EditMode 집중 시험 3/3 통과
- 기존 턴 마감 EditMode 회귀 시험 5/5 통과
- `SimulationWorldShell` 저장 Scene 회귀 시험 11/11 통과
- Unity Editor 스크립트 재컴파일 오류 0건
- 로컬 `Ssalddel.Simulation.Server` 상태 확인 200
- Play Mode에서 서버 제안 선택, 객체 반응 조회, Preview, Confirm과 기준 세션 재조회 확인
- 최종 검증 구간 Console 오류 0건

강조 원은 현재 카드 영향의 화면 표현일 뿐 생산·운송·입고·재고 완료를 뜻하지 않는다. 서버 Confirm과 기준 세션 재조회가 실제 Simulation 턴 전환의 근거다. 실제 운영 API, 주문, 결제, 기사 호출과 운영 재고 쓰기는 수행하지 않았다.
