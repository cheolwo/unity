# PolygonNature 숲 경관 배치 기준

## 팩의 특징

`PolygonNature`는 단일 나무를 반복하는 용도보다 산 능선과 큰 수관, 하층 식생, 바위와 수변 요소를 여러 크기의 덩어리로 겹쳐 로우폴리 자연 경관을 구성할 때 강점이 있다. 공공 공간자료가 배치 가능 위치를 결정하고 이 팩은 그 의미를 시각적으로 번역한다. 팩의 자산은 관측 사실이나 Simulation 상태를 생성하지 않는 표현 전용 자원이다.

- 나무는 활엽·침엽·혼효 수관의 큰 실루엣을 만든다.
- 식물은 숲 내부를 채우기보다 숲 가장자리와 시선이 머무는 전환부에 사용한다.
- 산·지형 조각은 DEM을 대체하지 않고 먼 거리의 능선과 지면 경계를 보강한다.
- 바위는 절개지와 급경사 전환을 읽히게 하되 이동로를 불필요하게 막지 않는다.
- 물·수변 요소는 관측 또는 파생 수계 마스크가 있을 때만 사용한다.
- 환경 움직임과 입자는 분위기 표현이며 실제 날씨·재난·생산 상태를 뜻하지 않는다.

## 배치 순서

경관은 다음 순서로 조립한다.

1. `Backdrop`: 산 능선과 먼 실루엣으로 지역의 외곽선을 정한다.
2. `Canopy`: 활엽·침엽·혼효림 군집을 큰 덩어리로 배치한다.
3. `Understory`: 숲과 경작지·도로가 만나는 가장자리를 관목과 낮은 식생으로 연결한다.
4. `TerrainTransition`: 바위 절개지와 지면 경계로 경사의 변화를 보강한다.
5. `Detail`: 작은 바위·풀·꽃은 이동로, 건물 주변, 군집 가장자리에만 제한한다.
6. `Fx`: 바람·낙엽·물결은 LOD와 사건 상태가 허용할 때 별도 표현 계층에서 켠다.

한 화면의 주역은 2~4개 큰 경관 덩어리로 제한한다. 개별 나무와 작은 소품을 균일 간격으로 뿌리지 않고, 세계 좌표 기반 결정적 seed로 같은 원본과 규칙에서 같은 경관을 재생성한다.

`A`, `B`, `C`는 같은 의미 세트 안의 결정적 시각 변형이다. 밀도 등급, 현실 수종, 상태 우선순위 또는 품질 등급으로 해석하지 않는다.

## LOD와 성능

- Overview에서는 산 능선과 HLOD 수관 실루엣만 유지한다.
- Region에서는 활엽·침엽·혼효림 군집과 바위 절개지를 보여준다.
- Task에서는 숲 가장자리, 수변 식생, 작은 바위와 제한된 환경 움직임을 추가한다.
- 수관 내부의 보이지 않는 개별 나무보다 군집의 외곽선과 빈 공간을 우선한다.
- Triangle, Material Slot, Draw Call, Shadow Caster, Collider, Animator 예산이 80%에 접근하면 Scene 적용 전에 검토한다.
- 충돌체는 플레이어 이동이나 상호작용에 필요한 큰 나무·바위에만 유지하고 장식 식생에는 기본적으로 두지 않는다.
- PC 기준 동적 그림자는 80m에서 끝내고 네 단계 Cascade를 사용한다. 45m 이후는 HLOD 대표 Renderer만 그림자를 만드는 후속 bake 대상으로 남긴다.
- `DetailRoot`는 그림자를 받기만 하고 `FxRoot`와 원경 능선은 동적 그림자를 만들지 않는다.

## 계절과 사건

- 봄·여름·가을·겨울은 원본 Material을 수정하지 않고 wrapper 또는 속성 변형으로 색조와 눈·이끼 반응을 적용한다.
- 평화 상태의 기본 움직임은 수목 흔들림과 제한된 주변 입자만 허용한다.
- 늪, 동굴 압력, 폐허 접근 흔적, 피해 현장, 계절 방어 전조는 평상시 경관에 섞지 않고 Simulation 사건 Overlay로 분리한다.
- 사건 Overlay의 표시나 환경 애니메이션은 실제 피해·전투·업무 완료의 근거가 아니다.

## 금지 요소

- 원본 자산의 경로나 내부 식별자를 공간·업무 계약과 문서에 기록하지 않는다.
- 실제 수종 근거 없이 특정 수종이나 과수원으로 확정하지 않는다.
- 수계 마스크 없이 수변 완충지·개울 회랑을 배치하지 않는다.
- 산 능선·바위 조각으로 DEM과 실제 경사를 대체하지 않는다.
- 법정동 경계를 나무벽·바위벽으로 둘러싸지 않는다.
- Farm·Hub·Town의 이동로와 업무 공간을 수관·바위·충돌체로 막지 않는다.

## 검토 체크리스트

- [ ] 큰 실루엣, 수관 군집, 가장자리, 세부 표현의 순서가 읽힌다.
- [ ] 모든 구성 세트가 허용 토지피복·경사·수계 조건을 지킨다.
- [ ] A/B/C가 현실 근거나 상태 등급으로 노출되지 않는다.
- [ ] Overview·Region·Task의 밀도와 HLOD 정책이 구분된다.
- [ ] 평화 경관과 Simulation 사건 Overlay가 분리돼 있다.
- [ ] 원본 자산 식별자가 문서와 배치 계약에 노출되지 않는다.
