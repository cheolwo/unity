# PolygonFarm 농촌 경관 배치 기준

## 팩의 특징

`PolygonFarm`은 밭·농장 마당·농기계·수확물 집하처럼 생산 공간의 작업 관계를 읽히게 하는 데 사용한다. 토지피복과 Scenario가 배치 가능 위치와 구체 작물을 결정하며, Prefab은 생산량이나 업무 완료를 확정하지 않는다.

- 밭은 개별 작물보다 지면과 밭고랑의 큰 블록을 먼저 만든다.
- Barn·농기계·수확 상자는 진입로와 작업 여유 공간을 남긴다.
- 특정 작물은 실제 자료나 `SimulationScenario` 근거가 있을 때만 사용한다.
- 농가와 생활 소품은 생산시설과 겹치지 않는 가장자리에 둔다.

## 배치 순서

1. 경작 블록과 농로로 큰 생산 구획을 만든다.
2. Barn·온실·농기계 대기장으로 작업 중심을 정한다.
3. 집하장·직판장·화물 연결 지점을 도로 쪽에 배치한다.
4. 울타리·수목 완충지로 경계를 연결하되 이동로를 막지 않는다.
5. 작은 작물·도구·상자는 Task 거리에서만 보강한다.

`A`, `B`, `C`는 같은 의미의 결정적 시각 변형이며 생산 단계나 품질 등급이 아니다.

## LOD와 성능

- Overview는 경작 블록과 Barn 실루엣만 유지한다.
- Region은 밭·작업마당·집하장 단위로 보여준다.
- Task는 작물·도구·상자와 상호작용 연결 지점을 추가한다.
- 충돌체와 그림자는 작업에 필요한 큰 건물·차량에 우선 배정한다.

## Simulation과 상호작용

- 실제 작물·화물·차량 상태는 Simulation 상태 사본을 따라 별도 Socket에 표현한다.
- 정적 트랙터나 상자는 업무 실행 중이라는 뜻이 아니다.
- 출입구, 농기계, 차량, 화물, 상호작용 Socket의 여유 공간을 Scene 적용 전에 검증한다.

## 금지 요소

- 원본 자산 식별자를 업무·공간 계약이나 공개 문서에 저장하지 않는다.
- 토지피복만으로 감자밭·과수원·생산량을 확정하지 않는다.
- 건물과 작물을 수계나 허용 경사 밖에 배치하지 않는다.
- 울타리와 소품으로 농로·출입구·화물 동선을 막지 않는다.

## 검토 체크리스트

- [ ] 큰 경작 블록에서 작업마당과 세부 소품 순서가 읽힌다.
- [ ] 작물의 근거가 Observed·StatisticallyAllocated·Scenario 중 하나로 명시됐다.
- [ ] 전체 Footprint와 작업 여유 공간이 로컬 제작 경계 안에 있다.
- [ ] A/B/C가 업무 상태나 품질 등급으로 노출되지 않는다.
- [ ] 정적 경관과 Simulation 상태 객체가 분리돼 있다.
