# 실제 높이·한강 선의 지구본 결속 r23

기존 로컬 Copernicus DSM N37E127 자료와 검증한 Natural Earth 한강 feature506을 사용한다. 경도127.05~127.95·위도37.05~37.95에 201×201 실제 높이 표본(약500m 간격), 80,000삼각형을 배치한다. 높이 1배, DSM3.56~1139.53m. 사진 텍스처 없음, 같은 지구본 곡면/카메라 사용.

지역 관찰에서 `산·강 표본`을 누르면 비스듬히 관찰한다. 수도권 확대 시에도 표시하고 멀리 나가거나 서울 상세로 들어가면 숨긴다. 로컬 Editor 검토 사본만 읽으며 Resources/Scene/배포에 DSM을 포함하지 않는다. 원본은 DSM으로 지표면/하상 자체가 아니며 한강은 개략 선자료를 DSM 위에 투영한 것이므로 수리학적 경사·강 폭 정확성을 주장하지 않는다.

최종 관련 EditMode19/19, 동일 생성hash 확인. 실제 Play의 01-relief.png는 산·강 표본 진입, 02-near.png는 북위37.72·동경127.55로 확대 초점을 바꾼 API-direct Game View다. 서울 평면 표현을 표본 관찰 중 숨겨 한강 일부 선이 가려지지 않게 했다. 한반도 원경에서 지형 숨김 확인 후 지구본 복귀·Play 종료. 물리 휠/버튼 입력 완주·빌드 검증은 아니다. 기존 서버 연결 오류·해양생활연출 경고가 남아 Console0은 아니다. Scene 저장·commit·push 없음.
