# 원두 배송 초벌 시각 표본

2026-09-23. 확정 디자인이나 운영 연결 화면이 아닌 기본 도형 샘플이다.

사용: SimulationWorldShell Play Mode → Tools/Mirror/원두 배송 시각 샘플 열기. 전체 보기/카페 보기/샘플 다시 보기/닫기. 기존 Scene 저장 없음. Editor 전용이며 빌드에는 포함하지 않는다.

트럭1대·가상 제조시설·카페·담당자2명. 4초 준비 후 26초 이동하고 인계 대기로 멈춘다. 서버·DB·물류 Command를 호출하지 않으며 샘플 시계는 실제 업무 상태가 아니다. 기존 지도 위 실제 좌표 결속은 후속이다.

- EditMode 표본 단계·끝점 시험6/6 통과(최초 import 직후0건 결과는 성공 증거에서 제외).
- 실제 Play: 8.78초 (-9.56,0,-2), 19.07초 (4.28,0,-2), 40.32초 (10,0,7)로 자동 이동 확인. 동일 표본 재열기 객체 수1 확인.
- `overview.png`: 이동 중 Game View. `cafe.png`: 자연 시간 경과 후 카페 앞 인계 대기 Game View. 시점 변경은 함수 호출로 확인했으며 물리 버튼 클릭 시험은 미수행.
- 기존 카메라 depth1000이 초안 depth900을 가리는 문제를 발견해 표본 depth2000으로 수정. DontSave 객체 검색도 Resources 조회로 수정.
- 기존 지구본의 위경도 글자가 일부 겹치는 문제, UI가 모형 일부를 가리는 문제는 남아 있다. Console 전체 오류0이나 운영 정상 흐름을 검증했다고 주장하지 않는다. Editor.log 마지막160행에 error/Exception 검색 일치 없음은 제한된 확인이다.
- 새 디오라마 규칙 후보 없음. 실제 지리 근거·업무 WI·E 승격·운영 연결·Windows 빌드·commit/push 없음.
