# 에셋연구-2 현실 관측 전시장

## 목표

신티 에셋을 단순한 장식물이 아니라 현실의 개념과 공공 관측 자료를 탐구하는 입구로 사용한다. 첫 세로 단위는 Farm Pack의 `감자 수확 상자 01`과 KAMIS 감자 가격 관측의 관계다.

에셋의 외형, 실제 공공 관측, 게임의 Simulation 값은 서로 다른 근거이므로 합치거나 서로를 대신하지 않는다. 실제 응답을 수집하지 않은 상태에서는 가격을 추정하거나 Fixture로 채우지 않고 `실제 관측 미수집`으로 표시한다.

## 우선순위

| 순위 | 연구 단계 | 상태 | 범위 |
| --- | --- | --- | --- |
| P0 | 출처와 의미 경계 | 완료 | 에셋 연구 Catalog와 현실 관측 Catalog 분리, source·관측 기간·지역·유통 단계·단위의 별도 보존 |
| P1 | 감자 상자 ↔ KAMIS | 완료 | 감자 수확 상자와 `product:potato`, KAMIS 품목 관계, 서버 조회 경로를 연결하고 미수집 상태와 Simulation 비교를 표시 |
| P2 | 실제 관측 투영 | 다음 | 서버가 보존한 지역·기간·유통 단계·품종·등급·단위·표본 수·출처 revision을 전시장 카드에 읽기 전용으로 투영 |
| P3 | Pack별 대표 에셋 확장 | 대기 | Farm 온실↔기상·농사로, Town 시장↔KAMIS, 물류시설↔창고 등록, City 정류장↔교통, 시청↔행정·인구·공공시설 |
| P4 | 탐구 동선 | 대기 | 에셋→장소→System→공공 관측의 관련 카드와 Scene 이동을 연결 |

P2에서 운영 응답이 실패하거나 자료가 없으면 마지막 성공 관측의 출처와 기준 시각을 보존하거나 미수집으로 남긴다. Simulation Fixture로 실제 관측 실패를 숨기지 않는다.

주택과 아파트는 공개된 집계 인구·세대 관측까지만 연결한다. 개별 주민, 가족 형태, 경제력 또는 사적 생활을 에셋으로 추론하지 않는다.

## 첫 전시 결과

![감자 수확 상자 현실 관측 전시장](감자상자-현실관측.png)

- 전시 이름: `감자 수확 상자 01`
- 현실 연결: `한국농수산식품유통공사(aT) KAMIS 일별 도·소매 가격정보`
- 제품 관계: `product:potato ↔ KAMIS category 100 / item 152 · Confirmed`
- 현재 실제 관측: `실제 관측 미수집`
- 알 수 없는 것: 선택한 상자의 실제 중량·품질·원산지·소유자·판매가격과 해당 농장의 출하 사실
- Simulation 비교: 기존 `2,450 KRW/kg`은 Simulation Fixture이며 현재 KAMIS 실제 관측값이 아님

## KAMIS 작물 모판

![KAMIS 작물 모판](KAMIS작물모판.png)

Farm 상품 Visual Catalog에서 `Direct`로 판정된 18종을 별도 모판으로 먼저 전시한다.

`감자, 콩, 양배추, 상추, 수박, 오이, 토마토, 딸기, 당근, 양파, 브로콜리, 사과, 배, 복숭아, 바나나, 오렌지, 레몬, 체리`

모판은 12개씩 두 쪽으로 구성한다. 각 표본은 한국어 이름, source prefab, canonical product stable ID, KAMIS 분류·품목코드, 시각 대응 `Direct`, 실제 관측 미수집 상태와 해석 한계를 함께 보여준다. 모판의 표본 수나 크기는 생산량·재고·가격을 뜻하지 않는다.

배추→양배추, 감귤→오렌지처럼 비슷한 외형을 빌리는 `Representative` 10종은 이번 모판에 섞지 않았다. 이후 `대표 표현 검토` 구역에서 오인 가능성을 먼저 연구한다.

## 감자 토양 모판

![감자 토양 모판](감자토양모판.png)

![감자 토양 모판 표본 호출 차단](감자토양모판-표본호출차단.png)

서로 다른 분류의 네 에셋을 하나의 연구 질문으로 묶었다.

- `밭고랑 토양 표본` ↔ 팜맵 기반 토양검정 정보 `15058655`
- `감자 재배체 표본` ↔ 작물별 토양적성도 조회 V2 `15144182`
- `감자 수확 상자 01` ↔ KAMIS 일별 도·소매 가격정보
- `밭 관수 스프링클러` ↔ 팜맵 기반 농업기상 정보 `15058627` 후보

카드는 `자료 후보 → 메타데이터 확인 → 표본 응답 확인 → 실제 관측 연결` 단계를 표시하고, 자료 ID·제공기관·공간·시간 기준·응답 형식·이용조건을 출처표에서 읽는다. 네 표본 모두 실제 응답을 수집하지 않았으므로 `실제 관측 미수집`이다.

공식 흙토람 작물 목록에서 감자는 `CR032`로 확인했다. 토양적성 API는 `STDG_CD` 법정동코드와 `soil_Crop_CD=CR032`를 요구하며, 기존 공통 인증키로 공개 예시 지역을 호출한 결과 HTTP 403 활용 미승인으로 차단됐다. 따라서 카드는 요청 경로와 차단 상태를 표시하되 `메타데이터 확인`에서 멈춘다.

### Scene으로 옮겨 심는 기준

1. canonical product stable ID와 KAMIS 품목 관계가 확인돼야 한다.
2. 사용할 prefab이 `Direct`인지 `Representative`인지 표시해야 한다.
3. 실제 관측에는 출처, 지역, 조사일, 유통 단계, 품종·등급·단위와 source revision이 있어야 한다.
4. 실제 관측이 없으면 `미수집`을 유지하고 Simulation Fixture로 채우지 않는다.
5. Scene의 작물 개수와 외형으로 실제 생산량·재고·품질을 계산하지 않는다.
6. 장소 역할과 작은 Simulation을 검증한 뒤 별도 VisualKey와 stable-ID mapping으로 Farm Scene에 승격한다.
