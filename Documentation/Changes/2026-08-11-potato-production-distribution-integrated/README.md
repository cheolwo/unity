# 감자 생산·유통 통합 흐름

개별 씬으로 유지하던 감자 생산·유통 단계를 하나의 통합 씬에서 순서대로 탐색할 수 있도록 구성했다.

## 통합 단계

1. 재배·수확
2. 수확·포장·상차
3. 농장 출발·거점 이동
4. 물류 거점 입고·검수
5. 물류 거점 판로 분배
6. 도시 도착

각 단계 버튼은 해당 단계의 기존 표현 루트와 UI를 활성화하고 카메라 초점을 전환한 뒤 대표 행동을 처음부터 시연한다. 같은 버튼을 다시 누르면 진행 중인 시연을 취소하고 처음부터 재생한다. 상품 계보는 같은 감자 상품과 수확 로트 맥락을 유지한다. 이 화면은 `Simulation` 표현이며 운영 확정이나 서버 명령을 수행하지 않는다.

- 1단계: 파종 검토 → 확인 → 생육 진행 → 수확
- 2단계: 포장 검토 → 포장 적용 → 상차 검토 → 상차 완료
- 3단계: 출발 검토 → 출발 적용 → Cargo 경로 이동 → 거점 도착
- 4단계: 입고 검토 → 입고 적용 → 품질 검수 → 합격·제외량 표시
- 5단계: 검수 통과 Lot 분리 → 도시 출고 후보 선택 → 후보 경로 표시
- 6단계: 도시 판매 지점에 상품이 전개되는 도착 연출 → 공개 상품 정보 표시

기존 8개 개별 씬은 회귀 확인과 개별 연구를 위해 그대로 보존했으며, 기존 씬과 에셋의 이름 및 `.meta` GUID를 변경하지 않았다.
