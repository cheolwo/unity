# 행정 경계 지구본 결속 r16

실제 SimulationWorldShell Play에서 서울 v3 검토 사본을 로드하고 같은 지구본 Camera로 서울(seoul.png), 중랑구(jungnang.png)를 촬영했다. ScreenCapture로 UI 포함. 함수 호출 검증이며 물리 입력 완주 증거는 아니다.

IsCurved=true, 89개 영역/Collider, 대표 면목7동 도형 Raycast 성공. 지구본 복귀 시 카메라 위치 (0,0,-53), near=.3 복원. 지명 겹침은 줄었지만 경계선 선명도와 광역 기호 잔여 시각 마감은 후속이다. 전국 자료·자동 로드·Console 오류 0 미검증. Play 종료, Scene 저장·commit·push 없음.
