# 신티 에셋 연구소 마을·도시 적용

## 결과

기존 농장 온실 연구 방식을 Town Pack과 City Pack에도 적용했다. 원본 자동 색인은 기존처럼 농장 498개·마을 702개·도시 335개, 합계 1,535개 Prefab을 보존한다. 연구 기록은 다음 세 대표 에셋으로 확장했다.

| 세계의 층 | 대표 에셋 | 한국어 의미 | 승격 후보 |
| --- | --- | --- | --- |
| 농장·생산 | 온실 01 | 시설재배 생산시설 후보 | `farm.facility.greenhouse` |
| 마을·생활 | 마을 단독주택 01 | 한 가구와 이웃의 생활 거점 후보 | `town.place.detached-house` |
| 도시·기능 | 도시 시청 01 | 행정 안내와 공공 업무의 도시 기능 거점 후보 | `city.place.civic-hall` |

세 항목은 모두 `해석됨` 상태다. 모델만으로 실제 생산량, 거주 인원, 소유 관계, 행정 기관·관할이나 운영 상태를 확정하지 않는다.

## 조작

하단의 `농장`, `마을`, `도시` 버튼으로 묶음을 직접 선택할 수 있다. 각 묶음의 건물 첫 쪽에서는 연구 기록이 있는 대표 에셋이 첫 번째로 정렬되고, 한국어 연구 카드가 함께 열린다. `분류`, `이전 쪽`, `다음 쪽`, `전체 보기`는 기존 기능을 유지한다.

## 검증

- Unity 스크립트 재컴파일: 성공, 컴파일 오류 0건
- `에셋연구-0 생성` 실행: 성공
- Scene 생성 검증에서 농장 12개·마을 12개·도시 12개 표본과 각 대표 연구 카드 확인
- Play Mode 직접 조회: 마을 건물 143개 중 첫 카드 `마을 단독주택 01`, 도시 건물 76개 중 첫 카드 `도시 시청 01`
- Unity 기본 EditMode 회귀: 57/57 통과
- 연구소 전용 NUnit 검사는 2개를 추가했으나 열린 Editor의 Test Runner가 이전 실행 상태를 복구하는 과정에서 `pipeline_test_status.json` sharing violation으로 멈춰 이번 실행 결과는 미수집
- 대체 검증으로 Builder의 `ValidateOpenScene`에 세 묶음 전환·12개 표본·대표 카드 일치를 포함하고, 생성 명령을 최종 코드로 다시 통과시킴
