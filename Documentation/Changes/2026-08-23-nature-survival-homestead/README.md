# Nature 생존 생활 거점

## 화면에서 달라질 내용

- canonical `SimulationWorldShell` 진입 시 Nature 생활 거점 세로 조각을 런타임에 조립한다.
- 기존 Synty 나무·그루터기·도끼·해골 자산을 사용하고, 오두막은 건설 단계가 읽히는 임시 블록아웃으로 표현한다.
- 마우스 왼쪽 버튼을 누르는 동안 벌목과 오두막 건설 작업이 누적되며, 간단한 상태 표시가 진행 상황을 보여준다.
- 새 공식 Scene을 만들거나 현재 저장 Scene을 덮어쓰지 않았다.

## 권위와 입력 경계

- 솔로 플레이의 Nature 상태는 로컬 결정 규칙이 소유하며 외부 서버가 없어도 동작한다.
- 전투 입력은 기존 전투 권위에 전달하고, 전투가 끝난 뒤에만 Nature 조우 결과를 반영한다.
- 입력 우선순위는 `전투 > Farm 배치 > Nature 문맥 행동`이다.
- 이 세로 조각은 Farm·Hub·Town·City의 독립 상태나 진행을 요구하지 않는다.

## 검증 수준

- Unity 솔루션 빌드: 경고 0개, 오류 0개
- 로컬 엔진 EditMode 시험 4건을 추가했으나, 사용자의 Unity Editor가 프로젝트를 열고 있어 별도 batch 실행은 중복 실행 방지로 차단됐다.
- 저장 Scene 배선 변경 없음. 런타임 자동 조립 코드와 순수 로컬 엔진 시험으로 구조를 검증했다.
- **Play Mode·Game View·실제 입력·Console은 미검증**이다. 따라서 이 기록에는 대표 PNG가 없으며 실제 화면 완료 증거로 간주하지 않는다.

## 남은 화면 검증

- 안전 공터 시작 위치와 나무·도끼의 실제 크기 및 도달 거리
- 누르고 있기 벌목/건설 입력, Farm 배치 입력과의 우선순위
- 오두막 단계별 가독성, 해골 임시 표현, 기존 전투 결과 인계
- 메뉴 및 앱 비활성 시 솔로 시간 정지
