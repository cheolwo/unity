# 수도권 해안 폴리곤 r21

기존 Natural Earth 광역 원본을 위도36~39·경도125~128에서 절단하고 0.1도 셀별 constrained triangulation으로 육지를 구성한다. 2,193 꼭짓점·2,738 삼각형. 섬/구멍을 유지하고 원본 면적과 일치 여부를 생성기에서 확인한다.

같은 지구본 곡면 위 관찰 중에만 해당 범위의 기존 거친 육지 메시를 교체하고 지구본 복귀 때 원본을 복원한다. 범위 밖 메시·운영 상태·Scene은 변경하지 않는다. 공식 최신 경계/고도 지형 완성은 아니며 절단 가장자리와 기존 자료의 연결 오차는 남을 수 있다.

최종 소스 재컴파일 후 EditMode 18/18. 새 Play에서 2,738개 삼각형 확인, 수도권 API-direct 진입 후 `capital.png` UI 포함 Game View 캡처. 해안 윤곽과 섬 분리가 표시되고 구면 법선 적용 후 기존 육지 색/조명이 이어짐을 확인했다. 원본 메시 복원/재사용 검증 후 지구본 복귀·Play 종료. 물리 입력 완주/Windows 빌드는 미검증. 기존 localhost:5204 연결 오류가 있어 Console 오류 0은 아니다. Scene 저장·commit·push 없음.
