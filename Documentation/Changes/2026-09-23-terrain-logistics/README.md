# 한반도 지형 위 물류 시각 표본 r7

기존 `GlobeVisualRoot`와 `한반도지형미리보기View`의 지형을 그대로 사용한다. 별도 지형판/공장 모형/Scene 없음. Tools/Mirror/한반도 지형 위 물류 샘플 메뉴를 canonical Scene의 Play Mode에서 연다.

- 이천권(37.27,127.44)→서울권(37.58,127.08)은 합성 거점/구면 보간 연결이다. 실제 시설·도로·배송 시간 근거가 아니다.
- 트럭은 표본40초 동안 이동 후 정지. 업무 인수/재고/운영 데이터 쓰기 없음.
- 한반도/수도권 카메라에서 같은 객체를 표시. 화면 검토 중 보조 선/해양 표현을 숨기고 닫을 때 복원하도록 구현.
- EditMode 구면반경3사례·종점 정지 총4/4. 최초 컴파일 실패 뒤0건 시험은 성공 증거가 아니다. 이름 충돌 수정 후4건 재실행 통과.
- 실제 Play에서 9.28초,15.94초의 다른 위치 확인. `peninsula.png`, `regional.png`는 Game View 캡처. 수도권은4도, 최종 한반도40도 시야각을 직접 적용해 캡처했고 코드에 동일 값 반영.
- 함수 호출 시점 변경 검증이며 물리 클릭/휠·전체 Console0·Windows빌드·운영 연결·5분 관찰은 미검증. 지형 원본 해상도/해안 픽셀 경계와 배경 국가 글자 위치는 현재 한계다. 실제 고도 Mesh나 도로망 개선 완료가 아니다.
- r6 별도 공장 모형은 사용자 의도와 달라 비채택 실험으로 보존. 이번 표본도 확정 디자인 아님. Scene 저장/commit/push·E승격 없음. 새 디오라마 규칙 후보 없음.
