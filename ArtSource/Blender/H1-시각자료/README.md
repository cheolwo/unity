# H1 시각 자료함

게임 기획에서 사용하는 H1 후보를 사람이 이미지로 검토할 수 있도록 모아 두는 로컬 자료함이다.

## 읽는 순서

1. 아래 목록에서 한국어 H1 이름을 고른다.
2. 각 폴더의 `README.md`와 검토 이미지를 본다.
3. 용도, 크기, 플레이어 설치 여부, 상태 변화 방향을 기획 대화에서 확정한다.
4. 승인 결과를 표현 배당 대장과 Presentation E4에 결속한다.

이 자료함의 이미지와 Blender/FBX 파일은 후보 검토 자료다. Unity Import, World 배치, 실제 입력, Renderer/Collider/Bounds 및 E5를 대신하지 않는다.

시각 검토의 기본 출력 단위는 `H1 하나 = Blender 파일 하나 = 대표 이미지 하나`다. 같은 H1에 상태 변화가 필요하면 상태별 `.blend`와 PNG를 각각 분리하고 상위 목록에서만 순서를 연결한다. 여러 H1을 합친 장면을 개별 H1 승인 근거로 쓰지 않는다.

다만 H1을 AreaSet 문맥에서 판독하기 위해, 독립 이미지와 별도의 `AreaSet 전체 조감도`를 같이 보여준다. 조감도는 배치·경로·인접 질문을 위한 문맥 자료이며, 개별 H1 승인은 여전히 독립 이미지에서만 판정한다. 쌍 검토 목록은 인접 `AreaSet-시각자료`에서 관리한다.

## 앞으로 추가할 항목

- H1 하나마다 한국어 폴더 하나를 사용한다.
- `검토 이미지`, `.blend`, 프로젝트 소유 `.fbx`, `검증결과.json`, `README.md`를 같은 폴더에 둔다.
- 공급사 원본은 이 자료함으로 복사하거나 수정하지 않고 경로·GUID·hash만 기록한다.
- 여러 H1을 조합하는 H2는 별도 H2 자료함에서 이 H1 항목들을 참조한다.
