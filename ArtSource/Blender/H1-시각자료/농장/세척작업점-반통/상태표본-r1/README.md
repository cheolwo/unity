# 농산물 세척 작업점 H1 — 반통 상태 표본 r1

공급사 반통 원본은 변경하지 않고, 세척 용도로 사용할 상태 표본에서만 중앙의 솟은 내부 면 13개를 낮춰 평탄한 세척조 파생형을 만들었다.

1. `01-빈반통`: 물·농산물·침전물이 없다.
2. `02-물채움`: 깨끗한 세척수만 있다.
3. `03-농산물세척중`: 깨끗한 물과 농산물 4개가 보인다.
4. `04-오염수배출대기`: 농산물은 빠지고 탁한 물과 침전물 2개가 남는다.

각 상태는 독립 PNG와 독립 `.blend`로 저장했다. 이 자료는 Presentation E4 상태 표본이며 실제 세척 동작, 수질, 급수·배수 연결, 저장 상태, Unity Scene과 E5를 입증하지 않는다.
