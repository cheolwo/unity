## 확정 용도

- H1 식별자: `h1-stock:farm-tool-storage`
- 후보 C를 휴대 도구와 정비 도구를 직접 읽게 하는 주 소품으로 채택한다.
- 후보 A를 삽·괭이·도끼 같은 대형·긴 농기구 보관을 지원하는 보조 보관함으로 채택한다.
- 후보 B를 공용 소모품과 예비 부품 보관 상자로 채택한다.
- 공간 H1 완성에는 지붕 또는 벽면, 긴 도구 거치, 꺼내기 Anchor와 작업 여백이 추가로 필요하다.

현재 상태는 `CandidateSetAccepted`다. 세 후보의 용도는 확정했지만 공간 전체 조립과 Unity E5는 아직 아니다.
