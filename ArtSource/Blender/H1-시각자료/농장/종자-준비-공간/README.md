## 확정 용도

- H1 식별자: `h1-stock:farm-seed-preparation`
- 한국어 표시명: `종자 준비 공간`
- 후보 A·B를 서로 다른 품종 또는 작업 단위의 소량 종자를 구분하는 소품으로 모두 채택한다.
- 후보 C를 대량 종자 또는 공동 보관을 나타내는 보조 소품으로 채택한다.
- 이 세 소품만으로 공간 H1이 완성되지는 않으며 선반·상자·작업 여백·접근 Anchor 조합을 후속 검토한다.

현재 상태는 `CandidateSetAccepted`다. 개별 소품 용도는 확정했지만 정확 조합, Unity Import, Collider/Bounds, 실제 상호작용과 E5는 아직 확정하지 않았다.
