# 농산물 세척 작업점 H1 — 긴 수조 상태 표본 r1

각 상태는 독립 PNG와 독립 `.blend`로 저장한다.

1. `01-빈수조`: 물·농산물·침전물이 없다.
2. `02-물채움`: 깨끗한 세척수만 있다.
3. `03-농산물세척중`: 깨끗한 물과 농산물 5개가 보인다.
4. `04-오염수배출대기`: 농산물은 빠지고 탁한 물과 침전물 3개가 남는다.

재개방 검사에서 각 상태의 물·농산물·침전물 가시 개체 수를 따로 확인했다. 이 자료는 Presentation E4 상태 표본이며 실제 세척 동작, 수질, 급수·배수 연결, 저장 상태, Unity Scene과 E5를 입증하지 않는다.
