## 주 후보 A — 차양형 농산물 작업대

- 이미지: [후보 이미지](주후보-농산물판매대-01/candidate.png)
- Blender 검토 사본: `주후보-농산물판매대-01/candidate-review.blend`
- 권장 의미: 수확 직후 농산물을 내려놓고 분류·포장·인계하기 전 잠시 다루는 반실외 작업점
- 빈 상태: 넓은 작업면과 차양만 보인다.
- 사용 중 상태: 수확 상자·작업 도구·작업자가 선택적으로 붙는다.
- 결과 상태: 출고 대기 상자나 빈 회수 용기가 놓인다.

차양과 작업면은 이 H1의 고정 골격 후보이고, 상자·농산물·도구·작업자는 WI와 권위 상태에 따라 붙는 가변 표현 후보로 둔다. 이미지 속 크기와 배치는 Unity World의 실제 배치 규칙이 아니며, H2 조립·Collider·Bounds·입력·E5를 입증하지 않는다.

## 작물 적재 표본 — 감자 상자

- 이미지: [감자 적재 상태](상태-감자상자-적재/감자-적재-상태.png)
- Blender 검토 사본: `상태-감자상자-적재/감자-적재-상태.blend`
- 적재 모듈: `SM_Prop_Box_Potato_01` 3개
- 구조: `공통 작업대 골격 + 교체 가능한 작물 적재 모듈`
- 사용자 결정: 채택

이 표본은 작업대 전체를 감자 전용으로 복제하지 않는다. 작물별 차이는 적재 모듈의 메시·색·용기·수량으로 표현하고, 빈 상태와 사용 중 상태는 같은 골격에서 모듈의 존재와 배치만 바꾼다. 현재 상자 위치와 수량은 시각 검토용이며 실제 작업 Anchor와 점유 규칙은 E5에서 다시 검증한다.
