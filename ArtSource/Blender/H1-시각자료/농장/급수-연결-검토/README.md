## 구조 제안

- 바닥 배치 호스는 길이·손상·통행 점유를 가진 `호스 H1`으로 둔다.
- 호스 릴과 손잡이는 보관·인출·개폐를 담당하는 `호스 릴 H1`으로 둔다.
- 두 H1을 자주 함께 쓰는 `급수 호스 세트`로 묶는다. 이 세트는 재사용 가능한 조립 구성이며 그 자체를 별도 H2로 세지 않는다.
- 스프링클러는 고랑에 물을 공급하는 선택 설치형 `관수 종단점 H1`으로 둔다. 기본 급수 호스 세트나 고랑 관수의 필수 구성은 아니다.
- 세척 수조는 농산물을 씻는 `세척 작업점 H1` 후보로 둔다.
- `급수 호스 세트 + 세척 작업점 H1 + 배수 처리점 H1`을 묶으면 `농산물 세척 공간 H2`가 된다.
- `급수 호스 세트 + 경작 구획 H1`만으로 수동 고랑 관수가 가능하다. 스프링클러 H1을 선택 설치하면 자동·반자동 살수 구성이 추가된다.
- Graph Map Edge는 H1 사이의 `연결됨`, `물을 공급함`, `현재 점유함` 관계를 표현한다. 호스가 H1이더라도 연결 관계는 별도 Edge로 유지한다.
- 연결에는 최소한 `급수원 Anchor`, `호스 릴 Anchor`, `호스 양끝 Anchor`, `소비점 Anchor`, `호스 길이`, `유량·압력`, `열림 상태`, `손상·누수`, `통행 방해`를 기록해야 한다.

현재 상태는 `ReusableH1BundleAccepted / OptionalSprinklerConfirmed / SimultaneousUseRulePending`이다. 공급사 원본은 변경하지 않았으며 실제 호스 변형, Unity 연결, 물 효과, 입력과 E5는 아직 검증하지 않았다.
