## 계층 제안

- 현행 `h1-stock:farm-washing`은 제목이 `농산물 세척 공간`이지만, 물의 출처·세척 설비·배수와 작업 여백을 모두 한 H1에 담으면 역할이 너무 커진다.
- H1은 한 사람이 접근하여 한 작업을 수행할 수 있는 `농산물 세척 작업점`으로 좁히는 것이 적합하다. 후보 D 또는 E를 주 설비로 하고 F를 보조 소품으로 결합할 수 있다.
- 우물과 급수탑은 세척 작업점과 독립적으로 관수·생활용수에도 쓰이는 `농장 급수점 H1` 후보가 자연스럽다. 둘은 농장 규모에 따른 대안이다.
- 자연 수로는 단독 세척 설비가 아니라 급수 접근 또는 수변 환경 Edge 후보로 보는 편이 적합하다. 평면 단독 렌더는 용도 판독 근거로 부족하다.
- `급수점 H1 + 세척 작업점 H1 + 배수·오수 처리 H1`을 묶은 상위 구성을 `농산물 세척 공간 H2`로 두는 방안을 제안한다.
- 기존 `h2-candidate:farm-wash-sort-pack`은 세척·선별·포장 전체 생산선이므로, 제안하는 세척 공간 H2보다 한 단계 넓은 조합으로 유지한다.

현재 상태는 `HierarchyProposalBlockedByWaterConnection`이다. 급수원과 소비점을 잇는 호스·밸브·유량·길이 규칙이 빠져 있어 H2 구조를 확정하지 않는다. 후보 렌더와 계층 제안만 만들었으며 기존 H 식별자·정의·상위 조합은 아직 변경하지 않았다. Unity Import·배치·WI 발현과 E5도 아니다.
