## 확정 용도

- H1 식별자: `h1-stock:farm-harvest-staging`
- 후보 A를 여러 수확물을 잠시 모으고 다시 꺼내는 주 적치 용기로 채택한다.
- 후보 B를 포장 완료 또는 품종 분리 상자로 채택한다.
- 후보 C를 수확물 자체의 용기가 아니라 적치 공간을 관리·수리하는 작업 도구 보조로 채택한다.
- 공간 H1 완성에는 수확 바구니·작물 표시·통행 여백·집하와 출고 방향을 구분하는 Anchor가 필요하다.

현재 상태는 `CandidateSetAccepted`다. 세 후보의 용도는 확정했지만 공간 전체 조립과 Unity E5는 아직 아니다.
