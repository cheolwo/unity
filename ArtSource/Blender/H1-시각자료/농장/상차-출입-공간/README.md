## 노드 우선 재검토

현행 `농장 상차·출입 공간 H1`에는 상태를 가지는 `상차 지점`과 두 지점 사이를 잇는 `차량 진입 경로`가 함께 들어 있다. 앞으로는 다음 순서로 검토한다.

1. 먼저 `상차 지점`의 안정 식별자·역할·소유 상태·상호작용 기준점·필수 화물 표현을 독립 노드로 확립한다.
2. 팔레트·팔레트 상자·대형 운송 상자는 이 노드의 상태별 가변 소품으로 연결한다.
3. 흙길·자갈길·아스팔트는 노드 자체가 아니라 진입 경로 Graph Map Edge와 배치 맵의 표면 후보로 보류한다.
4. 상차 지점 노드, 진입 경로, 정차·회전·보행 제약이 모두 정해진 뒤에만 상위 공간 조립과 H 계층 변경 여부를 판정한다.

이 기록은 현행 H 식별자를 즉시 삭제·분할하거나 새로운 H1/H2를 확정하지 않는다.

## 첫 H1 노드 정의 초안

- 작업 명칭: `농장 상차 지점`
- 기존 호환 참조: `h1-stock:farm-loading-gate`
- 노드 역할: 수확물 또는 포장 화물을 받아 팔레트·운송 상자 단위로 임시 적치하고 운송 주체에게 인계하는 작업 지점
- 입력 후보: 수확물 묶음, 포장 완료 화물, 빈 팔레트·회수 용기, 적치 작업을 수행하는 인력
- 출력 후보: 인계 가능한 화물 단위, 운송 주체에게 넘긴 화물, 반환되는 빈 팔레트·용기, 입출력 기록
- 기본 상태 흐름: `Available → ReceivingOrStacking → ReadyForPickup → HandedOffOrCleared`
- 예외 상태 후보: `CapacityBlocked`, `AccessBlocked`, `DamagedCargo`

입력이 들어오면 빈 공간에 화물 소품이 누적되고, 출력이 성립하면 해당 화물 소품이 빠지며 빈 팔레트·회수 용기 또는 비어 있는 작업면이 남는다. 인력은 입력 화물과 구분되는 수행 주체이며, 인력이 있다는 사실만으로 재고 출력이 완료되지는 않는다. 정확한 입력 승인 시점과 출력 인계 조건은 다음 문답에서 확정한다.

이 노드의 시각 검토는 통합 상태 비교판을 만들지 않는다. 먼저 `농장 상차 지점 H1` 자체를 독립 Blender 파일과 대표 이미지로 제시한다. 입력·적치·출력 상태가 필요해지면 같은 H1 폴더 아래 서로 다른 파일로 분리하며, 팔레트·상자·도로를 한 장면에 합친 결과는 개별 H1 승인 근거로 사용하지 않는다.

Construction Pack 보충 조사로 팔레트와 대형 운송 상자를 확인했다. 두 후보는 Farm·City 후보보다 건설·물류 현장의 큰 화물 소품으로 읽히므로 상차 공간의 가변 화물층에 적합하다. 반면 `Driveway`는 단독 렌더에서 차량 진입면보다 비정형 지형 전이 조각으로 보이고, `Barrier`는 차단기나 경계 표지가 아니라 돌망태 방호물에 가깝다. 따라서 F와 G는 이름만으로 진입 골격에 배당하지 않고 역할을 제한한다.

사용자 결정에 따라 A·B·D·E를 화물층 후보로 채택한다. C는 쓸 수 있지만 이번 답변에서 명시적으로 확정하지 않았으므로 검토 대기로 남긴다. H·I는 아스팔트 인상이 강하므로 농장 기본형에서 제외하고 도로 정비 이후의 발전된 타운 인접형으로 보류한다. J는 시티 인접형 후보다. City 팔레트는 공급사 단위 차이 때문에 Blender 검토 사본에서만 표시 배율 50을, City 도로와 표지는 표시 배율 100을 적용했으며 원본 FBX는 수정하지 않았다.

상차·출입 공간의 기본 구조는 `진입면 + 정차·상차 구획 + 회전·보행 여유 + 가변 화물층`으로 나눈다. 이번 채택은 마지막 화물층만 확정한다.

농장 기본형의 진입면은 흙길·자갈길처럼 농장 외곽과 자연스럽게 이어지는 비포장 표면을 우선한다. 아스팔트형 Town 후보는 동일 H1의 기본 외형이 아니라 도로 승격 뒤 선택되는 발전 상태 변형이다.

비포장 보충 조사에서는 Farm 자갈 직선로·T 접속로와 Construction 흙길 직선로를 확인했다. Construction 흙길은 단독 형상에서도 바퀴 자국이 있는 비포장 진입로로 가장 잘 읽힌다. Farm 자갈 도로 두 종은 형상 역할은 맞지만 현재 Blender 검토 Atlas에서 색이 옅게 보이므로 원 재질 대조 전에는 최종 색감 근거로 사용하지 않는다.

Unity 배치, 실제 크기 비교, Collider·Bounds·차량 접근, 적재 상호작용과 E5는 아직 검증하지 않았다.
