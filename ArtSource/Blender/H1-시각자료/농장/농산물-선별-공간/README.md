## 확정 용도

- H1 식별자: `h1-stock:farm-sorting`
- 후보 A와 B는 용도를 과도하게 세분하지 않고 모두 수확 후 출하 준비에 사용하는 선별 작업대로 채택한다.
- 후보 C는 선별한 농산물을 담는 나무 상자로 채택한다. 현재 검토 이미지는 빈 상자이며, 과일·농산물이 담긴 표현은 후속 상태 후보로 남긴다.
- 이 H1은 현재 `작업대에서 농산물을 선별하고 상자에 담을 수 있는 공간`까지만 소유한다. 운송·출고 등 후속 공정은 이 H1의 확정 범위에 포함하지 않는다.
- 실제 H1 조립에는 작업자 접근 면, 미선별 입구, 합격·보류·폐기 출구 Anchor와 통행 여백이 더 필요하다.

현재 상태는 `CandidateSetAccepted`다. 개별 소품 용도는 확정했지만 정확 배치 조합, 상자 내용물 상태, Unity Import, Collider/Bounds, 실제 WI 발현과 E5는 아직 확정하지 않았다.
