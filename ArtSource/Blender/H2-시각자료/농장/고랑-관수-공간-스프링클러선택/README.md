# 고랑 관수 공간 H2 연결 시안

![고랑 관수 공간 H2](H2-연결시안.png)

급수탑, 호스 릴·손잡이, 바닥 호스, 2.5×2.5m 경작 구획을 연결하고 선택 설치물인 스프링클러를 추가한 예시다.

- 스프링클러를 제거해도 호스 끝을 직접 사용한 수동 관수가 가능하다.
- 스프링클러는 자동·반자동 살수 표현을 켜는 선택 H1이다.
- 실제 살수 범위, 고랑 중앙 정렬, 물 소비량, 호스 통행 방해는 아직 미정이다.
- 그림의 거리와 호스 곡률은 설명용이며, 실제 Unity에서는 급수점과 선택한 고랑 또는 스프링클러 Anchor 사이에 맞춰 동적으로 표현해야 한다.
- E5에서는 연결점 Snap, 실제 필요 길이, 최대 허용 길이, 지면 추종, 장애물과 통행 간섭, 살수 도달 범위를 함께 검증한다.

상태: `DraftConnectedComposition_OptionalSprinklerShown`. Unity Scene·입력·물 효과·E5가 아니다.
