# 농장 상수도 수동 관수 연결 r1

## 구성

- `농장 상수도 급수점 H1`
- `호스 릴·손잡이 H1`
- `호스 H1`
- `2.5m×2.5m 경작 구획 H1`

## 상태 시안

1. `01-밸브닫힘-호스연결`: 파란 출수 소켓에 호스가 연결되어 있지만 빨간 차단 밸브가 닫혀 있어 물이 나오지 않는다.
2. `02-밸브열림-수동관수`: 빨간 차단 밸브의 가로·세로 살이 닫힘 상태에서 45도 회전하고, 손잡이 끝에서 고랑 쪽으로 물줄기가 나온다.

두 상태는 각각 PNG와 재개방 가능한 `.blend`로 저장했다. 닫힘 파일에는 물줄기 개체가 0개이고 열림 파일에는 5개이며, 출력 기준점 `Anchor_HoseOut`은 두 파일에서 동일하다.

## 증거 경계

이 자료는 독립 H1들의 연결 순서와 개폐 상태를 판독하는 Presentation E4 조립 시안이다. 실제 Unity 동적 호스, 수압·유량, 물 효과, Collider, 플레이어 입력, Scene 배치와 E5를 입증하지 않는다.
