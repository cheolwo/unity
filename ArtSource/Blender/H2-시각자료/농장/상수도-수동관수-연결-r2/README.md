# 농장 상수도 수동 관수 연결 r2

## r1 대비 보완

- 파란 호스가 출수구 중심에만 꽂혀 보이던 연결부를 제거했다.
- 외경 `0.108m`인 회색 출수 연결구를 외경 `0.126m`의 파란 체결 슬리브가 완전히 감싼다.
- 체결 슬리브 앞에는 감속 연결부를 두어 유연한 호스로 자연스럽게 좁아지게 했다.
- 밸브 열림 상태에서만 고랑 중앙에 젖은 흙 상태 2개가 나타난다.

## 상태 시안

1. `01-밸브닫힘-호스연결`: 체결 슬리브와 호스는 연결됐지만 물줄기와 젖은 흙이 없다.
2. `02-밸브열림-수동관수`: 빨간 밸브가 45도 회전하고 물줄기 5개와 젖은 흙 2개가 나타난다.

## 증거 경계

이 자료는 Presentation E4 조립 시안이다. 실제 나사·클램프 체결, 호스 변형, 수압·유량, 물리적 젖음 확산, 플레이어 입력, Unity Scene과 E5를 입증하지 않는다.
