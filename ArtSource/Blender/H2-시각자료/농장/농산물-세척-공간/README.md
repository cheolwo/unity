# 농산물 세척 공간 H2 연결 시안

![농산물 세척 공간 H2](H2-연결시안.png)

급수탑에서 호스 릴·손잡이로 물이 들어오고, 바닥 호스가 세척 수조로 이어지는 초안이다. 세척 수조의 사용수가 배수점으로 빠지는 연결도 별도 선으로 표현했다.

- 급수탑은 압력을 가진 급수원 예시다.
- 우물을 대신 쓰려면 펌프 H1 또는 동등한 압력 공급 장치가 추가로 필요하다.
- 각 연결선은 H1이면서 동시에 두 H1의 연결 관계를 나타내는 Edge 시각화다.
- 사람의 작업 위치, 화물 접근, 오염수 처리 방식과 안전 간격은 아직 미정이다.
- 그림의 간격과 호스 곡률은 설명용이다. 실제 Unity에서는 급수점·호스 릴·세척점의 World Anchor 사이 거리와 장애물을 읽어 호스 형상이 맞춰져야 한다.
- E5에서는 연결된 양끝, 실제 필요 길이, 최대 허용 길이, 지면 추종, 장애물 회피 또는 차단, Collider·통행 간섭과 물 공급 상태를 같은 배치 판본에서 확인한다.

상태: `DraftConnectedComposition`. Unity Scene·입력·물 효과·E5가 아니다.
