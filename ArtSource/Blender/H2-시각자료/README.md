# H2 연결 시각 자료함

여러 H1과 Graph Map Edge를 실제 배치처럼 조합해 사람이 연결성·간격·용도를 검토하는 로컬 자료함이다.

| H2 시안 | 상태 | 자료 |
| --- | --- | --- |
| 농산물 세척 공간 | 연결 배치 초안 | [세척 공간 시안](농장/농산물-세척-공간/README.md) |
| 고랑 관수 공간 | 스프링클러 선택 설치 예시 | [관수 공간 시안](농장/고랑-관수-공간-스프링클러선택/README.md) |

이 자료는 Blender 조립 시안이다. H1들이 연결되어 사용된다는 위상 관계만 보여주며 그림 속 거리·각도·호스 곡률은 고정 배치 규칙이 아니다. canonical H 정의, Unity Scene 배치, 실제 물 효과·입력, Renderer/Collider/Bounds 또는 E5를 대신하지 않는다.
