# AreaSet 시각 자료함

H1 개별 형상을 주변 노드·도로·작업 흐름 속에서 확인하기 위한 전체 조감도를 모은다.

- H1 개별 이미지: 형태·크기·상태 판독성 검토
- AreaSet 조감도: 배치·접근·이동 경로·주변 H1과의 관계 검토

두 이미지는 한 검토 쌍이지만 서로의 근거를 대신하지 않는다. 이 자료함은 로컬 Presentation E4 검토용이며 canonical AreaSet, Graph Map, 배치 맵, Unity Scene, E5를 변경하지 않는다.
